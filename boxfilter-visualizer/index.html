Guided walkthrough · exact emitted sequence

RVV: vertical sum, then two horizontal slides

Only three input loads occur per chunk. The two look-ahead lanes allow vslidedown(vertical, 1) and vslidedown(vertical, 2) to form overlapping windows entirely in registers.

for each output row y:
  for each vector chunk x:
    top = load(top_ptr + x, vl + 2);
    mid = load(mid_ptr + x, vl + 2);
    bot = load(bot_ptr + x, vl + 2);
    vertical = widen_add(top, mid);
    vertical = widen_add(vertical, bot);
    plus2 = slide_down(vertical, 2);
    sum = plus2 + vertical;
    plus1 = slide_down(vertical, 1);
    sum = sum + plus1;
    quotient = mul_high(sum, 7282);
    pixels = narrow_u8(quotient);
    store(output_ptr + x, pixels);
  // advance to the next three row-vector chunk

Implemented and assembly-checked: the C++ RVV kernel emits 3 loads, 2 widening additions, 2 slides, 2 horizontal additions, multiply-high, narrow, and 1 store, with no whole-register spills.
